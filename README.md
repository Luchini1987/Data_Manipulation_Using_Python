# Data_Manipulation_Using_Python
This project aims at showing good practices at the process of manipulating data using Python and Libraries as Pandas and Numpy.

During the process of data manipulation, the following stages have been covered :
+ Carrying out the process of data cleaning using ***Pandas***
+ Making specific changes with ***Numpy***
+ Handling date values using ***datetime***

The data frames used at this project, it have been retrieved from :

<https://www.kaggle.com/datasets/usdot/flight-delays?resource=download>
